# Pit Wall: Campus Customs dashboard

React 19 + Vite + TypeScript board for watching the agent team and approving payments.

```bash
npm install
npm run dev        # http://localhost:5173 (expects the backend on http://localhost:8000)
```

- API base: `src/config.ts` (override with `VITE_API_BASE`)
- Open a specific ticket: `http://localhost:5173/#ticket=101`
- Design notes: `../output/design.md`
